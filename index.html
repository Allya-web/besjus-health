月度健康打卡

客户每月月底通过手机填写（约 2 分钟）。打卡数据是季度 / 年度报告的核心输入，按「客户 + 年月」独立保存。

① 发送在「客户管理」卡片点「发打卡」，生成带客户 ID 的链接 / 二维码，发给客户。
② 填写客户在手机微信打开 checkin.html（已预填姓名/月份/客户ID），填写 4 部分。
③ 回传已开通云端直传：客户提交后打卡自动存入云端，管理端打开页面 / 切换客户 / 进入本页时会自动同步，无需任何手动操作；断网时自动降级为回传码方式。
④ 落库云端打卡自动归档到该客户档案（按「客户 + 年月」），重复提交自动取最新；如客户匹配不上，可点「云端记录」手动导入。
⑤ 串联季度报告页自动汇总该客户连续 3 个月打卡 → 生成季度小结 → 汇入年度总结。

打卡已自动同步：打开本页或切换客户时，系统会自动从云端取回该客户手机提交的打卡并落库，无需手动导入。手动「立即刷新」仅用于强制重拉；若客户匹配不上，请点「云端记录」查看云端全部数据并手动导入。

粘贴客户回传码（导入后即可查看打卡内容）

客户提交打卡后页面会显示一段「打卡回传码」。把客户发来的这段码粘贴到下面点「导入」，即可查看 / 编辑该月打卡内容（支持一次粘贴多行多个月份）。

复查检查单 · 当季基础指标覆盖

客户季度小结的「基础指标」表会按当季是否上传复查决定显示行：未复查时基础指标整体不显示；上传后按"入组异常 + 当季复查覆盖"匹配展示。本面板提供健管师粘贴文本 / 客户回传码两条录入路径，存到客户档案 retests["Q*_YYYY"]。（v56：客户也可在手机「月度打卡」提交后，点「一并上传复查单」拍照/传文件自动识别，生成同一回传码）

① 邀请发「打卡链接」即可（客户提交打卡后页面会出现「一并上传复查单」入口，拍照/传文件自动识别，推荐）；也可点「发复查链接」生成 retest.html 二维码单独邀请。
② 填写客户在手机微信打开 retest.html，选复查季度（Q1/Q2/Q3/Q4）+ 年份，录入 15 项基础指标或粘贴整段报告原文。
③ 回传客户提交后产生回传码 / 数据链接，发送给健管师；也可由健管师直接把客户发来的复查报告文本粘贴到下方文本框。
④ 归档数据落到该客户档案 retests["Q3_2026"]，下次生成季度 / 年度报告时基础指标表自动按"异常 + 覆盖"匹配行。
上传复查单照片 / 文件（自动识别）

与体检报告识别同一引擎：手机拍的复查单照片（推荐，图片 OCR 需联网）或 PDF / Word / 文本电子版均可。识别结果自动归档到下方所选季度，无需手打。

粘贴客户复查报告文本（健管师代填）

把客户复查报告中可读到的文字结论（如"LDL-C 2.8 mmol/L、空腹血糖 5.6 mmol/L、血尿酸 360 μmol/L..."）粘贴到下面，系统会自动抽取并归档到当前季度 Q?_YYYY。原始文本与抽取结果可在下方核对。

粘贴客户复查回传码

客户在 retest.html 提交后会得到一段「复查回传码」或「数据链接」。把这段码粘贴到下面点「导入」，即可归档到客户档案对应季度。
